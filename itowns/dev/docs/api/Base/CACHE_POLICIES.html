CACHE_POLICIES

Cache policies for flushing. Those policies can be used as the cacheLifeTime property of a layer.

Properties

INFINITE : number

The entry is never flushed.

TEXTURE : number

Shortcut for texture resources. Time is 15 minutes.

GEOMETRY : number

Shortcut for geometry resources. Time is 15 minutes.
