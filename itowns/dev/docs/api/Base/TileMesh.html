TileMesh

A TileMesh is a THREE.Mesh with a geometricError and an OBB. The objectId property of the layered material is assigned to the id of the TileMesh.

Constructor

TileMesh ( geometry: TileGeometry, material: LayeredMaterial, layer: TileLayerLike, extent: Extent, level: number )

Parameters

  • geometry —

    The tile geometry
  • material —

    A THREE.Material compatible with THREE.Mesh
  • layer —

    The layer the tile is added to
  • extent —

    The tile extent
  • level (optional) —

    The tile level (default = 0)

Methods

findCommonAncestor ( tile: TileMesh ) : TileMesh|undefined

Finds the common ancestor between this tile and another one. It goes through parents on each side until one is found.

Returns

The common ancestor between those two tiles, or undefined if not found

Parameters

  • tile —

    The tile to find common ancestor with
