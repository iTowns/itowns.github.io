SunLightLayer

Manages directional lighting and shadows as a layer. Updates the sun light position and shadow camera parameters based on the current camera view and sun direction.

Constructor

SunLightLayer ( forceDaytime: boolean, shadowsMaxAltitude: number, sunTiltAltitude: number )

Parameters

  • forceDaytime (optional) —

    Indicates whether to force daytime lighting regardless of the scene's time.
  • shadowsMaxAltitude (default: 30000) —

    Specifies the maximum altitude at which shadows are cast.
  • sunTiltAltitude (default: 30000) —

    Specifies the maximum altitude at which the sun tilts when forceDaytime is true

Methods

update ( context: UpdateContext )

Updates the sun light position and its target to shine on what the camera sees. Dynamically adjusts the shadow box size to minimize flickering while covering the visible area.

Parameters

  • context —

    The update context.
