WebXR

Handler of a webXR session

Constructor

WebXR ( view: GlobeView, options: object )

Parameters

  • view —

    The view where the webXR session will be started
  • options (optional) —

    WebXR configuration - its presence alone enable WebXR to switch on VR visualization.
    • options.callback (optional) —

      WebXR rendering callback.
    • options.controllers (optional) —

      Enable the webXR controllers handling.

Properties

vrControls : VRControls

WebXR controllers handler
