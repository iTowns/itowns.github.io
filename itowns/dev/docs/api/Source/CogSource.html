CogSource

A source for Cloud Optimized Geotiff (COG) data.

Such data consists of a GeoTIFF file that stores a georeferenced image and downsampled versions of this image. The original image is always the first image in the COG file. The downsampled versions are called "overviews". They share the same position and geographic extent with the original image. Their resolution (in distance per pixel) however is higher.

A freshly created CogSource fetches and parses the header and metadata for each image (original and overviews) from the file into an array of nodes. Each of these nodes contains information about an image (origin, resolution...) and an accessor to get the actual image data. This array is what CogSource's parser later uses to create textures that contain the COG file data.

At the moment, iTowns only displays data either as single band or RGBA textures. Therefore, a COG image with a number of samples other than 1, 2 or 3 won't be displayed.
