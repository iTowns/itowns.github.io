Coordinates

A class representing a geographic or geocentric coordinate.

A coordinate is defined by a CRS (Coordinate Reference System) and a 3-dimensional vector (x, y, z). For geocentric projections, it is recommended to use the latitude, longitude and altitude aliases to refer to vector components.

To change a value, prefer the use of the set* methods.

By default, the EPSG:4978 and EPSG:4326 projections are supported. To use a different projection, it must have been declared previously with proj4. A comprehensive list of projections and their corresponding proj4 string can be found at epsg.io.

Constructor

Coordinates ( crs: ProjectionLike, x: number, y: number, z: number )

Parameters

  • crs —

    A default or user-defined CRS (see ProjectionLike).
  • x (optional) —

    x or longitude value.
  • y (optional) —

    y or latitude value.
  • z (optional) —

    z or altitude value.

Example

Geocentric coordinates 
new Coordinates('EPSG:4978', 20885167, 849862, 23385912);
Geographic coordinates 
new Coordinates('EPSG:4326', 2.33, 48.24, 24999549);
Defining the EPSG:2154 projection with proj4 
proj4.defs('EPSG:2154', `+proj=lcc +lat_0=46.5 +lon_0=3 +lat_1=49 +lat_2=44
+x_0=700000 +y_0=6600000 +ellps=GRS80 +towgs84=0,0,0,0,0,0,0 +units=m
+no_defs +type=crs`);

Methods

applyMatrix4 ( mat: Matrix4 )

Multiplies this coordinate (with an implicit 1 in the 4th dimension) by mat, and divides by perspective.

Parameters

  • mat —

    The matrix.

as ( crs: ProjectionLike, target: Coordinates ) : Coordinates

Projects this coordinate to the specified CRS.

Returns

The coordinate projected into the specified CRS.

Parameters

  • crs —

    The target CRS to which the coordinate will be converted.
  • target (optional) —

    The target to store the projected coordinate. If this not provided a new coordinate will be created.

Example

Conversion from a geographic to a geocentric reference system 
const geographicCoords = new Coordinates('EPSG:4326',
    2.33,        // longitude
    48.24,       // latitude
    24999549,    // altitude
);
const geocentricCoords = geographicCoords.as('EPSG:4978');
Conversion from a geocentric to a geographic reference system 
const geocentricCoords = new Coordinates('EPSG:4978',
    20885167,    // x
    849862,      // y
    23385912,    // z
);
const geographicCoords = geocentricCoords.as('EPSG:4326');

Copies the (x, y, z) vector components and crs of the passed coordinate to this coordinate.

Parameters

  • src —

    The source coordinate to copy from.

geodeticDistanceTo ( coord: Coordinates )

Computes the geodetic distance from this coordinates to coord. Geodetic distance is calculated in an ellipsoid space as the shortest distance across the curved surface of the ellipsoid.

Parameters

  • coord

planarDistanceTo ( coord: Coordinates )

Computes the planar distance from this coordinates to coord. Planar distance is the straight-line euclidean distance calculated in a 2D cartesian coordinate system.

Parameters

  • coord

Sets the coordinates's (Coordinates#x|x) component to array[offset + 0], (Coordinates#y|y) component to array[offset + 1] and (Coordinates#z|z) component to array[offset + 2].
