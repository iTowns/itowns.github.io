OBB

Represents an oriented bounding box.

Constructor

OBB ( min: THREE.Vector3, max: THREE.Vector3 )

Parameters

  • min (optional) —

    (optional) A THREE.Vector3 representing the lower (x, y, z) boundary of the box. Default is ( + Infinity, + Infinity, + Infinity ).
  • max (optional) —

    (optional) A THREE.Vector3 representing the upper (x, y, z) boundary of the box. Default is ( - Infinity, - Infinity, - Infinity ).

Methods

clampZ ( zmin: number, zmax: number )

Clamped the OBB on the z axes of the OBB.box3D.

Parameters

  • zmin —

    The min z value for clamping.
  • zmax —

    the max z value for clamping.

copy ( cOBB: OBB )

Copies the property from cOBB to this OBB.

Parameters

  • cOBB —

    OBB to copy

isSphereAboveXYBox ( sphere: THREE.Sphere ) : boolean

Determines if the sphere is above the XY space of the box.

Returns

true if the sphere is above the XY space of the box, false otherwise.

Parameters

  • sphere —

    The sphere

projOBB ( crsIn: ProjectionLike, crsOut: ProjectionLike )

Project the OBB in a specified crs. The OBB new position will be the initial OBB center projected at z=0 in the initial crs.

Parameters

  • crsIn —

    The initial crs (at the creation of the OBB)
  • crsOut —

    The crs in which we want the obb to be projected

setFromExtent ( extent: Extent, minHeight: number, maxHeight: number ) : this

Computes the OBB from an extent. The OBB resulted can be only in the system 'EPSG:3946'.

Returns

return this object

Parameters

  • extent —

    The extent (with crs 'EPSG:4326') to compute oriented bounding box
  • minHeight (optional) —

    The minimum height of OBB
  • maxHeight (optional) —

    The maximum height of OBB

updateZ ( elevation: Object )

Updates the z min, z max and z scale of oriented bounding box.

Parameters

  • elevation (optional) —

    Elevation parameters
    • elevation.min (optional) —

      The minimum elevation
    • elevation.max (optional) —

      The maximum elevation
    • elevation.scale (optional) —

      The scale of the elevation
    • elevation.geoidHeight (optional) —

      The geoid height
